            Jury Focus: Where Does the System Misdiagnose?
          
        

        

          

            A critical jury question is: "Where does it misdiagnose?" This matrix documents the boundary conditions where naive LLMs fail, and the architectural safeguards we implemented to resolve them.
          

          

            

              
                

                  Failure Mode Category
                  Root Cause of Misdiagnosis
                  Observed LLM Behavior
                  Our Multi-Layer Mitigation
                

              
              
                

                  Vendor Dialect Specifics
                  Non-standard functions (e.g. Postgres ILIKE, T-SQL TOP N, Oracle NVL)
                  Models trained on web code emit foreign dialect operators unsupported by host SQLite engine.
                  Dialect-grounded system prompts + rule-assisted dialect AST translation before execution.
                

                

                  Semantic Ambiguity in Multi-Table Projections
                  Shared column identifiers across parent/child tables (e.g. id, name) without aliases
                  Without conversational intent, LLM must guess whether author wanted parent or child key.
                  Schema foreign-key relationship graph traversal + confidence score degradation warnings.
                

                

                  Correlated Subquery Aggregation
                  Selecting unaggregated column alongside MAX() in SQLite
                  SQLite returns arbitrary row for unaggregated columns; LLMs fail to realize logic requires a subquery.
                  ANSI SQL strictness audit flagging non-deterministic projection rows.
                

                

                  Adversarial DDL Piggybacking
                  Stacked semicolons chaining DROP TABLE or 1=1
                  Naive models attempt to format or complete the malicious command.
                  AST Safety Guardrail: Zero LLM execution permitted; intercepted and blocked at parser layer.
